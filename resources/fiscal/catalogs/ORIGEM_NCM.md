# Catálogo NCM

Fonte oficial: Receita Federal / Sistema Classif.

URL pública: `https://portalunico.siscomex.gov.br/classif/api/publico/nomenclatura/download/json`

O arquivo `ncm_oficial.json` é uma cópia integral obtida da fonte acima. O NabiCode valida estrutura, códigos e metadados antes de substituir a cópia local.
