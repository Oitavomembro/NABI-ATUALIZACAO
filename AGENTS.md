# Entrada obrigatória no projeto

Antes de analisar, planejar, alterar arquivos, executar testes ou usar Git neste
repositório, toda pessoa ou agente que estiver entrando no projeto pela primeira
vez deve:

1. ler integralmente `MAPA_SUCESSAO_NABICODE_2026-08-23.md`;
2. conferir no mapa o que já foi concluído, o que falta e o ponto exato de retomada;
3. confirmar o estado real do Git (branch, HEAD e árvore de trabalho) sem apagar
   nem sobrescrever alterações locais;
4. respeitar os bloqueios, limites de escopo e autorizações registrados no mapa;
5. atualizar o mapa ao encerrar uma etapa relevante, mantendo evidências, commit
   de referência, pendências e próximo passo.

Em caso de divergência entre o mapa e o checkout, pare e apresente a divergência
ao responsável antes de modificar o projeto. O histórico existente não deve ser
reescrito e nenhum push deve ser feito sem autorização explícita.
